Mikan **0.1.3 beta.6**, build **10201019**.

- Updated Citrus to `dev` commit **843a37008f6f65e441a531647efb6afb8194959c**, including recent security, transport, uTLS and ResTLS fixes. About displays the pinned core revision. Native build inputs now include the core commit so a core update cannot reuse an old library.
- Fixed automatic subscription refresh timing, plain subscription names being mistaken for Base64, and active-profile selection after deletion.
- Clear live group caches after profile reload, including the Subscriptions tab. Operator network-stack, sharing and bypass policy changes apply from successful fetch snapshots; changed TUN stacks explain when a reconnect is needed.
- Recognize Chain groups in live and offline views. The picker has pinned group headers with working controls, deliberate pull-to-dismiss with a spring return, and a unified protocol/transport/TLS capsule. Built-in outbounds no longer get a false TCP badge.
- Added Android XDrive local-storage protection, including externally supplied provider nodes. Read-only displays hide storage credentials while raw node configuration remains available for full offline connection tests.

Version **0.1.3**, application ID **io.github.miroshka000.mikan**, build **10201019**. The release signing key is unchanged. Use **mikan-alpha-arm64-v8a.apk** for a modern Android phone, or **mikan-alpha-universal.apk** for all architectures. Checksums: **SHA256SUMS.txt**.

This pre-release does not replace the latest stable release.
