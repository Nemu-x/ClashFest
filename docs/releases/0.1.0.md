The first Mikan release for Android.

- Mikan's orange theme and refreshed app screens.
- A lower, centered empty-subscription message on the home screen.
- Subscription management, traffic usage and server selection.
- Flexible routing with AND / OR / NOT, no-resolve, app selection, bulk paste and a text rule editor.
- User rules are retained when subscriptions update; the VPN core validates the configuration before it is applied.
- Compact settings and protection against repeated taps in the main navigation.

For modern Android phones, download **mikan-alpha-arm64-v8a.apk**. The **mikan-alpha-universal.apk** supports all included architectures. Separate armeabi-v7a, x86 and x86_64 APKs are also available.

This is an optimized **0.1.0 release build**, signed with the permanent MikanApp key. APK SHA-256 hashes are included in the release.

Debug builds use a different signing key. Back up your subscriptions and settings before uninstalling a debug build and switching to release.
