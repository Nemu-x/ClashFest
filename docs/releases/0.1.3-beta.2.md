Signed beta build of Mikan **0.1.3**, Android build number **10201015**.

- Redesigned the app with soft Material 3 surfaces, a consistent type system and an animated mandarin connection button.
- Added ambient background motion and state-driven icon animations. Motion pauses when the UI is hidden and respects Android's animation settings.
- Added country flags and kept server latency and protocol badges in place when names are long.
- Made subscription refresh results visible on the home screen, lists and open sheets, with clear error messages and retry actions. Repeated requests wait for the actual update result.
- Included PR #8: the About screen names the bundled core correctly as Citrus.
- Integrated PR #5 with the current Citrus core. Its TrustTunnel connection, handshake timeout and dead-session fixes are already upstream; their tests now run in the app's CI without duplicate patches.

The displayed application version stays **0.1.3**. The application ID and release signing certificate are unchanged. Install the signed APK over the existing Mikan release to keep subscriptions and settings. A future update must use a build number higher than **10201015**.

For most modern Android phones, use **mikan-alpha-arm64-v8a.apk**. **mikan-alpha-universal.apk** includes every supported architecture. APK hashes are in **SHA256SUMS.txt**.

This is a GitHub pre-release and is not marked as the latest stable release.
