Mikan **0.1.3 beta.4**, Android build **10201017**.

- Added a connected liquid selection indicator to the bottom navigation. Its leading edge moves first and its tail follows through a soft bridge. Rapid tab changes continue from the currently drawn shape; motion stops when the UI is hidden and respects system animation settings.
- Made the bottom bar slightly shorter: 76 dp instead of 80 dp at the normal text size. Its outer width is unchanged.
- Navigation captions use a clearer 12 sp Manrope weight, wrap instead of truncating, and keep their full text. Larger system text can increase the bar height; page padding follows it so content remains reachable.
- Fixed **Choose server** on subscription cards: it now uses the existing subscription-data loading handler before opening the picker, rather than opening an empty sheet immediately. The working Home picker and protocol metadata path are preserved.

Application ID: **io.github.miroshka000.mikan**. Displayed version: **0.1.3**. Build number: **10201017**. The Mikan release signing key is unchanged. Updating a Play installation also requires a compatible signing certificate or valid key rotation.

For a modern Android phone, use **mikan-alpha-arm64-v8a.apk**. **mikan-alpha-universal.apk** includes all supported architectures. The filename's `alpha` is the build flavor, not an application-ID suffix. Hashes are in **SHA256SUMS.txt**.

This is a pre-release and is not marked as the latest stable release.
