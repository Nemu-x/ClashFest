Mikan **0.1.3 beta.5**, build **10201018**.

- Replaced the pinched navigation shape with a smooth expanding capsule. Only the selected tab reveals its label; Routing is now **Rules**. Standard height is 64 dp, with the existing outer width preserved. Narrow layouts and larger text use a shared caption instead of splitting words or shrinking touch targets.
- Theme palettes now preview their actual resource colors in light and dark mode, display names, and mark the effective selection. Wallpaper colors clear a conflicting custom accent; operator styling and Obsidian explain their priority.
- Corrected text colors on preset secondary and tertiary surfaces. Long theme controls have room to wrap naturally. Reset now restores font weight and the default Mikan color settings.
- Background options now distinguish **Calm** from **Animated** across screens. Color changes refresh the main screen through its existing soft recreation path; font scaling still reapplies the activity configuration.
- The subscription server picker fix from beta.4 is included.

Application ID: **io.github.miroshka000.mikan**. Version: **0.1.3**. Build: **10201018**. The release signing key is unchanged.
