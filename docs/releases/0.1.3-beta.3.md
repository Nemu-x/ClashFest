Signed beta of Mikan **0.1.3**, Android build **10201016**, targeting the Google Play application ID **io.github.miroshka000.mikan**.

- Corrected the APK application ID to match the Play edition, without the legacy `.alpha` suffix. Future APK releases use the same ID.
- Increased the build number from 10201015 to 10201016. The displayed version remains 0.1.3.
- Includes the Material 3 redesign, ambient animation, country flags, subscription refresh feedback and the merged Citrus/TrustTunnel changes from the previous beta.

The APK uses the existing Mikan release certificate. Updating an installed Play edition also requires a compatible signing certificate or a valid signing-key rotation. A Play installation still using the old key cannot be updated by this APK solely by matching its application ID.

For a modern Android phone, download **mikan-alpha-arm64-v8a.apk**. **mikan-alpha-universal.apk** supports all included architectures. The filename's `alpha` identifies the build flavor; the actual application ID is **io.github.miroshka000.mikan**. Hashes are in **SHA256SUMS.txt**.

This is a pre-release and is not marked as the latest stable release.
