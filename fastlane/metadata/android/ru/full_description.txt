ClashFest — прокси/VPN-клиент для Android с маршрутизацией по правилам на ядре mihomo (Clash.Meta).

<b>Сделан для обычного пользователя</b>: вставил или отсканировал ссылку на подписку, нажал «Подключить», готово. Подписка не переписывается, все правки живут отдельным слоем поверх неё.

<b>Возможности</b>
<ul>
<li>VLESS (REALITY, XHTTP, Vision), VMess, Trojan, Shadowsocks, Hysteria2, TUIC, WireGuard, SSH, mieru и другие протоколы ядра mihomo</li>
<li>Подписки в формате Clash YAML с заголовками оператора (квота, срок, объявления, брендинг)</li>
<li>Маршрутизация по приложениям, наборы правил, свои правила, редактор DNS и hosts, туннели</li>
<li>Группы прокси прямо на главном экране: выбор ноды, проверка задержки одной ноды или всей группы</li>
<li>Живые соединения и логи</li>
<li>Безопасно по умолчанию: локальные SOCKS/HTTP-слушатели закрыты, гео-базы только с доверенных зеркал</li>
<li>Сканер QR без сервисов Google</li>
<li>Управление ТВ-приставкой в той же сети</li>
</ul>

<b>Приватность</b>: без аналитики, без трекинга, без сервера разработчика. Трафик идёт на серверы выбранного вами оператора.
